# Patches written by xdelta3

`lzma.xdelta`, `djw.xdelta` and `fgk.xdelta` were written by xdelta3 3.1.0 (built from its
source with liblzma 5.8.1), one per secondary compressor, several windows each. Sources and
targets are generated bytes, no game: the source is `MakeRom(200000, 1)` of `../encoders.h`,
the targets are made by `make_vectors.py`, which also writes these files again and prints
the sizes and CRC-32 the tests expect. The FGK patch has no source: see the script for why.
